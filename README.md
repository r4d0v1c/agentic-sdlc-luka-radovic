# Agentic SDLC: Building a Software Factory

Course repository for the Agentic SDLC course. Over six modules I build a
set of Kiro CLI agents that automate the stages of the software development
lifecycle: Git workflow, architecture, requirements, CI/CD, and test-driven
development. The final module combines all agents in an individual project.

## Course Progress

- [x] Module 1: Git - workflow agent
- [x] Module 2: Software Architecture - arc42 design agent
